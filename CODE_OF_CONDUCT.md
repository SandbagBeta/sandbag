# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be welcoming, no harassment, no gatekeeping (grade-shaming included). Spray responsibly.

Climbing-specific addendum: respect access. Advocating for ignoring closures, trespassing, or publishing deliberately-hidden locations is a conduct violation here, not just a data-policy issue.

Report issues to the maintainers via GitHub (private security advisory or maintainer email in the org profile). Enforcement follows the Contributor Covenant's enforcement guidelines.
